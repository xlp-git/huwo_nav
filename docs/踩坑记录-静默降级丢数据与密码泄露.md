# Cloudflare Pages 前端项目踩坑：静默降级丢数据、VITE_ 变量泄露密码、Workers 解析超限

## 背景

2026-09-24 对虎窝导航（React + Vite + Cloudflare Pages Functions + KV）做全量代码审查时发现的几类问题，都是"看起来能用、实际有坑"，其他 Pages/Workers 小项目很容易重复踩到。

## 内容

### 1. API 失败静默降级到 localStorage，导致保存"假成功"

- **现象**：线上编辑后界面正常显示，刷新页面改动消失。
- **原因**：存储层写法是"先请求 API，失败（含 4xx/5xx）就改写 localStorage 并返回成功"。本意是方便本地开发（没有 KV），但线上 API 一旦报错也会被吞掉；下次加载从 KV 读到的是旧数据，覆盖了本地缓存。
- **解决**：按运行环境区分，不按"请求是否失败"区分：
  - `import.meta.env.DEV` 为真（`vite dev`）→ 全部读写 localStorage；
  - 生产环境 → 读取失败可回退缓存（只读），**写入失败必须抛错并提示用户**。
- **经验**：降级只适合读，写操作静默降级等于丢数据。

### 2. `VITE_` 前缀的环境变量会被打包进前端 JS

- **现象**：编辑密码用 `import.meta.env.VITE_PASSWORD` 在前端校验，任何人打开开发者工具搜索打包文件即可看到明文密码。
- **原因**：Vite 会把所有 `VITE_` 前缀变量在构建时内联进客户端代码，它们本质上是公开配置，不是机密。
- **解决**：密码放服务端环境变量（Cloudflare Pages 设置为"加密"），在 `functions/api/_middleware.js` 中统一校验写请求；前端只把用户输入的密码放在内存里随请求头发送。
- **细节**：
  - 请求头只能是 ISO-8859-1，中文密码需 `encodeURIComponent` 编码、服务端 `decodeURIComponent`，畸形编码要 try/catch；
  - 比较时先 SHA-256 摘要再逐字节异或，避免按长度或前缀提前返回；
  - 未配置密码时应拒绝写入（503），不要默认放行；
  - 本地开发用的默认密码写在 `if (import.meta.env.DEV)` 分支里，生产构建会整段删除，可用 `grep -r 密码 dist` 验证。

### 3. 在 Workers 免费版里解析上传的大文件会超 CPU 限额

- **现象**：收藏夹导入接口在书签多时失败（Workers 免费版每次请求约 10ms CPU）。
- **原因**：浏览器导出的收藏夹 HTML 内嵌大量 base64 图标，几千个书签就有 1MB 以上；原解析算法还是对每个链接重扫全文（O(n²)）。即使改成线性单遍扫描，大文件的正则解析仍会超限。
- **解决**：解析放到浏览器端，只把精简后的 `[{ name, url, category }]` JSON 上传；服务端只做校验、去重、合并。
- **经验**：Workers 免费版上，任何"与上传体积成正比"的计算都尽量前移到客户端。

### 4. sticky 侧栏首屏下半截在屏幕外

- **现象**：左侧分类栏 `position: sticky; max-height: calc(100vh - 32px)`，页面上方还有时钟和搜索区，首屏时侧栏下半截落在屏幕外；恢复到靠下的分类时，即使滚动了侧栏列表，选中项也看不到。
- **原因**：`max-height` 按"吸顶后"的位置设计，没考虑吸顶前侧栏从页面中部开始。
- **解决**：用 JS 在 scroll / resize / `document.body` 尺寸变化时（rAF 节流），把最大高度设为"视口高 − max(当前顶部, sticky top) − 间距"；判断选中项是否可见时，用"侧栏与视口的交集"而不是侧栏自身的可视区域。

### 5. 小坑

- **`box-sizing: border-box` 下定宽要算上边框**：按"10 个汉字 140px + 内边距"算出 176px，实际文字区少了 2px 边框，10 个字被截断；改 180px。
- **`animation-fill-mode: both` 会覆盖 `:hover` 的 transform**：入场动画结束后仍保持最终关键帧，导致悬停上浮失效；改用 `backwards`。
- **修改 `vite.config.js` 的同时删除其引用的入口文件**：Vite 自动重启失败、开发服务器直接退出，需要手动重启。
